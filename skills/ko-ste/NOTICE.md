# ko-ste 출처 고지

이 기본 스킬의 직접 작성한 지침·설명·예문·코드는 MIT로 제공한다. 참조한 MIT 자료의 저작권과 허락은 `UPSTREAM-LICENSES.md`에 있다.

공개 한국어 글쓰기 자료와 STE의 오독 방지 목표를 참고했다. 공식 ASD-STE100 규칙·승인 사전이나 토스 가이드 원문을 포함하지 않는다. 공인 한국어 STE 표준이나 ASD의 공인을 뜻하지 않는다.

국립국어원 원문 예문은 기본 스킬과 분리한 선택 자료다. 이를 추가했다면 `NIKL-NOTICE.md`의 공공누리 조건을 따른다. 직접 작성한 검토 메모와 외부 인용문은 구분한다.

자료별 상세 출처: https://github.com/fivestar1103/ko-ste/blob/main/THIRD_PARTY.md

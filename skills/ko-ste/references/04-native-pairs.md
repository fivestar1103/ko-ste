# 사람이 고친 전후 쌍과 사용자 수정

이 파일은 원자료 위치와 프로젝트의 검토 메모를 담는다. 국립국어원의 보기·권장 표현 자체는 변경 금지 조건이 있어 MIT 기본 배포본에 포함하지 않는다. [국립국어원 원자료](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=&etc_seq=700&pageIndex=1) 또는 [저장소의 전후 쌍](https://github.com/fivestar1103/ko-ste/blob/main/research/nikl-native-pairs.md)에서 확인한다.

원자료: 국립국어원 「쉬운 공문서 쓰기 길잡이」(2022), 발간등록번호 11-1371028-000915-01. PDF SHA-256: `50fe05a794ba375ce12773e8f4a11aa664d1e8fa321fb2db0d1f810dc4845fe4`. 아래 쪽 번호는 책에 인쇄된 번호다. 조회일: 2026-10-07.

사용자가 별도 예문 자료를 설치했다면 같은 폴더의 `nikl-native-pairs.md`에서 실제 전후 쌍을 읽는다. 그 파일의 원문 인용은 공공누리 제3유형을 따른다. 해당 파일이 없어도 스킬을 사용할 수 있다. 원문을 읽지 않고 전후 쌍을 확인했다고 말하지 않는다.

같은 유형의 수정은 사용자 쌍(U-), 원문을 확인한 채택 쌍(NP-), [설명용 LLM 예문](02-examples.md)의 순서로 참고한다. 제외 쌍(X-)은 의미 보존의 본보기로 쓰지 않는다. 공식 권장 표현도 원문의 조건이나 강도를 바꾸는지 확인한다.

## 사용자 수정 쌍 (U-)

현재 등록된 쌍은 없다. 사용자가 직접 쓴 문장만, 사용자의 동의를 받아 기록한다. 회사 정보와 개인 정보는 기록하지 않는다. 공개 저장소에 제공할 쌍은 작성자가 MIT로 제공할 권한이 있는 문장이어야 한다. LLM이 다시 고친 문장을 사람이 고친 쌍으로 기록하지 않는다.

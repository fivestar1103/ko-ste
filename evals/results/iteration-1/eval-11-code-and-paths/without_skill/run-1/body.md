`~/.config/app/settings.json` 파일에서 `retry_count`를 3 이상으로 설정하면 `--force` 옵션 없이도 재시도할 수 있습니다.

**바꾼 부분**
- **"설정 시" → "설정하면"**: 딱딱한 한자어 대신 자연스러운 연결 어미를 썼습니다.
- **"재시도 수행이 가능합니다" → "재시도할 수 있습니다"**: 명사를 겹쳐 쓴 표현을 동사로 풀었습니다.
- **"옵션 사용 없이도" → "옵션 없이도"**: "사용"은 없어도 뜻이 같아서 뺐습니다.
- **"파일의" → "파일에서"**: 파일 안의 값을 설정한다는 뜻이 더 분명해집니다.
- **"`retry_count` 값을" → "`retry_count`를"**: 키 이름만으로 무엇을 가리키는지 알 수 있습니다. 문서 전체에서 "값"을 붙여 쓰고 있다면 그대로 두세요.

한 문장 안에서 주어가 '사용자 → 링크 → 사용자'로 바뀌어 읽기 어려워서 문장을 나눴습니다.

**다듬은 문장:**

> 비밀번호 재설정 링크를 요청하면 이메일로 링크가 발송됩니다. 이 링크는 30분 후에 만료되며, 만료된 후에는 링크를 다시 요청해야 합니다.

**바꾼 점**
- **주어를 분명히 함:** 문장마다 무엇을 말하는지 드러나도록 '링크가', '이 링크는'을 넣었습니다.
- **문장을 나눔:** 링크 발송과 링크 만료는 서로 다른 내용이라 두 문장으로 나눴습니다.
- **조건을 분명히 함:** '30분이 지나면 만료되고 다시 요청해야'를 '30분 후에 만료되며, 만료된 후에는 다시 요청해야'로 바꿨습니다. 다시 요청해야 하는 때가 만료된 뒤라는 점이 분명해집니다.
- **'사용자가'를 뺌:** 안내문은 보통 사용자에게 직접 말하므로 주어 '사용자가'는 빼도 자연스럽습니다. 시스템 명세 문서라면 '사용자가 비밀번호 재설정 링크를 요청하면…'처럼 그대로 두셔도 됩니다.

**더 짧게 쓴 예:**
> 비밀번호 재설정 링크는 이메일로 발송되며 30분 동안 유효합니다. 링크가 만료되면 다시 요청하세요.

## 수정본 (엄격 모드)

1. 설정 파일을 엽니다.
2. `port` 값을 `8080`으로 바꿉니다.
3. 설정 파일을 저장합니다.
4. 서버를 중지합니다.
5. 기존 서버 프로세스가 종료되었는지 확인합니다.
   - 프로세스가 아직 실행 중이면 4단계를 다시 합니다.
6. 서버를 시작합니다.

### 바꾼 점
- **한 단계에 동작 하나:** 원문은 한 문장에 동작 다섯 개(열기, 바꾸기, 저장, 확인, 재시작)가 들어 있었습니다. 이것을 번호 단계로 나누었습니다.
- **순서대로 배치:** 원문에서는 "재시작하되, 재시작 전에"처럼 뒤에 오는 조건이 앞 동작을 거슬러 올라가 바꿉니다. 이제 확인 단계가 시작 단계보다 먼저 나옵니다.
- **"재시작"을 나눔:** "재시작"은 중지와 시작을 한 단어에 담고 있어서, 확인 단계가 그 중간에 들어갈 자리가 없었습니다. 그래서 중지(4단계)와 시작(6단계)으로 나누었습니다.
- **실패할 때의 처리 추가:** 원문에는 프로세스가 종료되지 않았을 때 무엇을 할지 나와 있지 않았습니다. 5단계에 조건 문장을 넣었습니다.
- **어미 통일:** 모든 단계를 "~합니다"로 끝냈습니다.

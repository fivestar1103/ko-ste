## 수정 결과 (엄격 모드)

1. 설정 파일을 여세요.
2. `port` 값을 `8080`으로 바꾸세요.
3. 설정 파일을 저장하세요.
4. 기존 서버 프로세스가 종료되었는지 확인하세요.
   - 프로세스가 실행 중이면 프로세스를 종료하세요.
5. 서버를 시작하세요.

## 바꾼 내용

- **한 단계에 한 동작만 둠**: 원문은 한 문장에 동작이 다섯 개 있었습니다. 이를 번호가 붙은 단계 다섯 개로 나눴습니다.
- **실제로 할 순서대로 배치함**: 원문은 "재시작하되, 재시작 전에 확인하세요"였습니다. 이 문장은 확인을 재시작보다 뒤에 적었습니다. 그래서 확인 단계(4)를 시작 단계(5) 앞에 두었습니다.
- **조건부 동작을 명시함**: 원문은 "종료되었는지 확인"만 지시했습니다. 프로세스가 실행 중일 때 할 일이 없었습니다. 그래서 하위 항목을 추가했습니다.
- **"재시작"을 "시작"으로 바꿈**: 4단계에서 기존 프로세스를 이미 종료합니다. 따라서 5단계의 동작은 "시작"입니다.
- **용어를 통일함**: 같은 대상에는 계속 "설정 파일", "서버 프로세스"라는 같은 이름을 썼습니다.
- **값을 코드 서식으로 표시함**: `port`와 `8080`은 사용자가 그대로 입력하는 값입니다. 그래서 코드 서식으로 구분했습니다.

설정 파일 경로, 프로세스 확인 명령, 서버 시작 명령을 알려 주시면 각 단계에 넣어 드리겠습니다.

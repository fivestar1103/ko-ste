**다듬은 문장:**

> A형은 포진성 구협염과 수족구병을, B형은 심근염과 흉막통을 일으킴. 두 유형 모두 사람이 유일한 숙주임.

**고친 점:**
- **'-며'가 두 번 이어지던 문장 정리:** "일으키며 … 유발하며"를 "A형은 ~을, B형은 ~을 일으킴"으로 묶었습니다. A형과 B형이 나란히 대비되어 읽기 쉬워집니다.
- **'사람이 유일한 숙주임'을 별도 문장으로 분리:** 원문에서는 이 부분이 B형에만 해당하는 것처럼 읽힐 수 있습니다. 콕사키바이러스는 A형, B형 모두 사람이 유일한 자연 숙주이므로 "두 유형 모두"를 넣어 적용 범위를 분명히 했습니다.
  - 만약 B형에만 해당한다는 뜻이었다면 이렇게 쓰면 됩니다: "B형은 심근염과 흉막통을 일으키며, 사람이 유일한 숙주임."

**한 문장으로 쓰려면:**
> A형은 포진성 구협염과 수족구병을, B형은 심근염과 흉막통을 일으키며, 두 유형 모두 사람만을 숙주로 함.

다듬은 문장:

> `~/.config/app/settings.json` 파일에서 `retry_count`를 3 이상으로 설정하면 `--force` 옵션 없이도 재시도할 수 있습니다.

**바꾼 점**
- **설정 시 → 설정하면**: '~시'를 '~하면'으로 바꿔 조건이 더 자연스럽게 읽힙니다.
- **`--force` 옵션 사용 없이도 → `--force` 옵션 없이도**: '사용'은 빼도 뜻이 같습니다.
- **재시도 수행이 가능합니다 → 재시도할 수 있습니다**: 명사를 겹쳐 쓴 표현을 동사로 풀었습니다.
- **파일의 `retry_count` 값을 → 파일에서 `retry_count`를**: 조사를 정리했고, 키 이름만으로 뜻이 통해서 '값'을 뺐습니다.

경로, 키 이름, 옵션 같은 코드 요소는 그대로 두었습니다.

**다듬은 문장:**

> `~/.config/app/settings.json` 파일에서 `retry_count`를 3 이상으로 설정하면 `--force` 옵션 없이도 재시도할 수 있습니다.

**바꾼 부분:**
- **설정 시 → 설정하면**: 명사형 "~시" 대신 조건을 나타내는 연결 어미 "~하면"을 써서 문장이 자연스럽게 이어집니다.
- **`--force` 옵션 사용 없이도 → `--force` 옵션 없이도**: "사용"은 없어도 뜻이 같아서 뺐습니다.
- **재시도 수행이 가능합니다 → 재시도할 수 있습니다**: "수행이 가능합니다"는 명사를 여러 번 겹친 번역투 표현이라 동사로 바꿨습니다.
- **`retry_count` 값을 → `retry_count`를**: 설정 항목이라는 것이 문맥에서 분명해서 "값"을 뺐습니다. 값이라는 점을 강조하고 싶다면 그대로 두셔도 됩니다.

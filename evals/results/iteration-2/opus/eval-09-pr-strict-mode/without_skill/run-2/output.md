엄격 모드에서는 문장 하나에 내용 하나만 담고, 짧은 능동형 평서문을 쓰고, 용어와 수치를 일관되게 적었습니다.

**다듬은 문장**

> 로그인 API는 응답을 캐시합니다.
> 캐시를 사용하면 평균 응답 시간이 약 120ms에서 약 40ms로 줄어듭니다.
> 캐시 만료 시간의 기본값은 5분입니다.
> 설정 파일에서 캐시 만료 시간을 변경할 수 있습니다.

**바꾼 부분**

| 원문 | 수정 | 이유 |
|---|---|---|
| 이번 PR에서는 … 추가하였으며 | (삭제) | PR은 개발 과정의 정보입니다. 사용자 안내문에는 기능이 지금 어떻게 동작하는지만 적습니다. |
| 응답 캐싱을 추가하였으며, 이를 통해 … 감소하였습니다 | 두 문장으로 나눔 | 문장 하나에 내용 하나만 담았습니다. "이를 통해"처럼 앞 문장을 가리키는 말도 없앴습니다. |
| 약 120ms에서 40ms로 | 약 120ms에서 약 40ms로 | 두 값이 모두 대략적인 값임을 분명히 했습니다. |
| 감소하였습니다 | 줄어듭니다 | 쉬운 말을 쓰고 현재 시제로 적었습니다. |
| 설정되어 있으며 | 기본값은 5분입니다 | 수동형을 없앴습니다. 사용자가 바꿀 수 있는 값이므로 "기본값"이라고 적었습니다. |
| 변경이 가능합니다 | 변경할 수 있습니다 | 명사로 끝나는 표현을 동사형으로 바꿨습니다. |

**더 넣으면 좋은 내용:** 설정 안내문이므로 사용자가 바로 따라 할 수 있게 설정 파일 이름, 키 이름, 값의 단위를 함께 적으면 좋습니다. 아래는 예시입니다.

> 캐시 만료 시간을 변경하려면 `config.yaml` 파일에서 `auth.cache_ttl` 값을 초 단위로 지정합니다.

`config.yaml`과 `auth.cache_ttl`은 임의로 넣은 이름입니다. 실제 파일 이름과 키 이름을 알려 주시면 그대로 반영하겠습니다.

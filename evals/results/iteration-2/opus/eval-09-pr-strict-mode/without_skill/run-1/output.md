**다듬은 문장**

> 로그인 API는 응답을 캐시에 저장합니다. 그 결과 평균 응답 시간이 약 120ms에서 약 40ms로 줄어듭니다.
> 캐시 만료 시간의 기본값은 5분입니다. 설정 파일에서 이 값을 변경할 수 있습니다.

**바꾼 점**

- **"이번 PR에서는" 삭제:** 사용자 안내문의 독자는 PR을 모릅니다. 변경 이력 대신 현재 동작을 설명했습니다.
- **한 문장에 한 내용:** "~하였으며", "~되어 있으며"로 이어진 긴 문장을 짧은 문장 네 개로 나눴습니다.
- **현재형과 능동형 사용:** "추가하였으며"는 "저장합니다"로, "감소하였습니다"는 "줄어듭니다"로, "설정되어 있으며"는 "기본값은 ~입니다"로 바꿨습니다.
- **"기본값" 사용:** 사용자가 바꿀 수 있는 값이므로 "기본값"이라고 쓰는 것이 더 정확합니다.
- **쉬운 말 사용:** "변경이 가능합니다"는 "변경할 수 있습니다"로, "감소"는 "줄어듭니다"로 바꿨습니다.
- **"약"을 두 숫자에 모두 붙임:** 두 값이 모두 측정한 평균임을 분명히 했습니다.

**확인할 점:** 설정 안내문이라면 설정 파일 경로와 키 이름을 함께 쓰는 것이 좋습니다. 예: "`config.yaml`의 `auth.cache_ttl` 값을 변경합니다." 실제 경로와 키를 알려 주시면 문장에 넣겠습니다.

이번 PR에서 로그인 API 응답 캐싱을 추가했습니다. 평균 응답 시간이 약 120ms에서 40ms로 줄었습니다. 캐시 만료 시간은 기본 5분이며, 설정 파일에서 바꿀 수 있습니다.

**바꾼 내용**
- "추가하였으며, 이를 통해" 부분은 두 문장으로 나누고 "이를 통해"를 뺐습니다.
- "감소하였습니다"는 "줄었습니다"로, "변경이 가능합니다"는 "바꿀 수 있습니다"로 풀었습니다.
- "설정되어 있으며"는 "기본 5분"으로 줄였습니다. 원문에서는 5분이 기본값인지 현재 설정값인지 불분명해서, 기본값으로 읽고 썼습니다. 현재 설정값이라는 뜻이면 "5분으로 설정되어 있으며"로 되돌려 주세요.
- 수치와 사실 관계는 그대로입니다.

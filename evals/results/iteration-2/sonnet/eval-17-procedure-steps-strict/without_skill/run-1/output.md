엄격 모드로 고친 문서입니다. 한 단계에 동작 하나만 두고, 재시작 전에 종료 확인을 통과 조건으로 넣었습니다.

1. 설정 파일을 엽니다.
2. `port` 값을 `8080`으로 변경합니다.
3. 파일을 저장합니다.
4. 기존 서버 프로세스를 종료합니다.
5. 기존 프로세스가 종료되었는지 확인합니다. 프로세스 목록에 해당 프로세스가 없어야 합니다.
   - 프로세스가 남아 있으면 6단계로 진행하지 않습니다. 종료될 때까지 4~5단계를 반복합니다.
6. 5단계의 확인이 끝난 경우에만 서버를 시작합니다.

원문은 "서버를 재시작하되, 재시작 전에 종료를 확인"이라는 한 문장이라 순서가 모호했습니다. 그래서 종료(4)와 확인(5), 시작(6)을 따로 나눴고, 종료 확인 실패 시의 처리도 명시했습니다.

설정 파일 경로, 프로세스 종료·확인 명령어는 원문에 없어서 추측해 넣지 않았습니다. 알려주시면 4~5단계에 구체적인 명령과 기대 출력을 넣겠습니다.

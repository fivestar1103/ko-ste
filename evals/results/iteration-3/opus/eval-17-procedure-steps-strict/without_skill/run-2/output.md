## 수정안 (엄격 모드)

1. 설정 파일을 엽니다.
2. `port` 값을 `8080`으로 바꿉니다.
3. 설정 파일을 저장합니다.
4. 서버를 중지합니다.
5. 기존 서버 프로세스가 종료되었는지 확인합니다.
   - 프로세스가 종료되지 않았다면 6단계를 진행하지 마십시오.
6. 서버를 시작합니다.

## 바꾼 점

- **한 단계에 동작 하나:** 원문의 한 문장에는 동작이 다섯 개 있었습니다. 이를 번호를 붙인 단계로 나눴습니다.
- **순서와 실행 순서를 일치:** 원문은 "재시작하되, 재시작 전에 확인하세요"처럼 나중에 할 일을 먼저 쓰고 조건을 뒤에 붙였습니다. 사용자는 이 순서를 따라 하다가 확인 단계를 놓칠 수 있습니다. "재시작"을 **중지 → 확인 → 시작**으로 나눠서 확인 단계가 제자리에 오게 했습니다.
- **실패 시 동작 명시:** 확인에 실패하면 어떻게 할지 원문에는 없었습니다. 다음 단계로 넘어가지 않도록 하위 항목을 추가했습니다.
- **어미 통일:** 모든 단계를 "-합니다"로 맞췄습니다. 금지 지시만 "-하지 마십시오"를 썼습니다.
- **값 표기:** `port`, `8080`은 사용자가 그대로 입력하는 값입니다. 그래서 코드 서식으로 표기했습니다.

설정 파일 경로, 서버 중지·시작 명령, 프로세스 확인 방법(예: `ps`, `tasklist`)을 알려 주시면 각 단계에 넣겠습니다.

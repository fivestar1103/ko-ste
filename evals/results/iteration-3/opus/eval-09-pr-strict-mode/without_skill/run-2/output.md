엄격 모드(한 문장에 한 가지 내용, 능동형, 짧고 명확한 표현, 용어 통일) 기준으로 다듬었습니다.

```
로그인 API는 응답을 캐시에 저장합니다.
이 기능으로 평균 응답 시간이 약 120ms에서 약 40ms로 줄었습니다.
캐시 만료 시간의 기본값은 5분입니다.
설정 파일에서 캐시 만료 시간을 변경할 수 있습니다.
```

**바꾼 점**

- **"이번 PR에서는" 삭제**: 사용자용 설정 안내문에서는 PR이 필요 없는 개발 맥락입니다. 기능이 지금 어떻게 동작하는지만 설명했습니다.
- **문장 분리**: 두 개의 긴 복문을 네 개의 단문으로 나눴습니다. 한 문장에 한 가지 내용만 담았습니다.
- **번역투·명사형 정리**: "추가하였으며", "이를 통해", "감소하였습니다", "변경이 가능합니다"를 "저장합니다", "이 기능으로", "줄었습니다", "변경할 수 있습니다"로 바꿨습니다.
- **"설정되어 있으며" → "기본값은"**: 사용자가 값을 바꿀 수 있으므로 5분이 기본값임을 분명히 했습니다.
- **"약" 범위 명확화**: 두 수치 모두 근사값으로 보고 각각 "약"을 붙였습니다. 40ms가 정확한 값이면 두 번째 "약"을 빼세요.

설정 파일 경로와 키 이름(예: `cache.login.ttl`)을 알려주시면 마지막 문장에 넣어서 바로 따라 할 수 있는 안내로 바꿔 드리겠습니다.

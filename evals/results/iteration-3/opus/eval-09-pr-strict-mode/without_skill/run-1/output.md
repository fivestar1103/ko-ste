## 다듬은 문장

> 로그인 API는 응답을 캐시합니다.
> 캐시를 사용하면 평균 응답 시간이 약 120ms에서 약 40ms로 줄어듭니다.
> 캐시 만료 시간의 기본값은 5분입니다.
> 설정 파일에서 캐시 만료 시간을 변경할 수 있습니다.

## 바꾼 점

- **"이번 PR에서는 … 추가하였으며"를 삭제했습니다.** 설정 안내문의 독자는 PR 이력이 필요하지 않습니다. 독자에게는 현재 동작만 설명합니다.
- **한 문장에 한 가지 정보만 담았습니다.** 원문 두 문장에 정보가 네 개 들어 있어서 네 문장으로 나눴습니다.
- **연결 어미를 없앴습니다.** "-하였으며", "-되어 있으며", "이를 통해"를 짧은 평서문으로 바꿨습니다.
- **피동 표현을 줄였습니다.** "설정되어 있으며"는 "기본값은 5분입니다"로, "변경이 가능합니다"는 "변경할 수 있습니다"로 바꿨습니다.
- **용어를 통일했습니다.** "캐싱"과 "캐시"가 섞여 있어서 "캐시"로 통일했습니다.
- **"5분"을 "기본값"으로 명시했습니다.** 사용자가 바꿀 수 있는 값이기 때문입니다.
- **"약"은 남겼습니다.** 측정 평균값이라 "약"을 빼면 사실보다 정확한 것처럼 읽힙니다. 두 값이 모두 근삿값이어서 "약"을 양쪽에 붙였습니다.

## 보완하면 좋은 점

"설정 파일"과 해당 항목이 구체적이지 않습니다. 파일 경로와 키 이름을 넣으면 사용자가 바로 따라 할 수 있습니다. 예:

> `config.yaml` 파일의 `login.cache_ttl` 값으로 캐시 만료 시간을 변경할 수 있습니다.

실제 파일명과 키를 알려주시면 반영하겠습니다.

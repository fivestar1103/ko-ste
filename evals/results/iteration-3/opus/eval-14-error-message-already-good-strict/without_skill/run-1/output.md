## 판정: 그대로 써도 됩니다

엄격 기준으로 봐도 큰 문제는 없습니다.

| 항목 | 평가 |
|---|---|
| 문장 길이 | ✅ 세 문장 모두 짧습니다. |
| 한 문장에 한 내용 | ✅ 결과, 원인, 조치가 각각 한 문장입니다. |
| 어미 통일 | ✅ 모두 '-습니다/-십시오' 체입니다. |
| 능동·직접 표현 | ✅ 주어와 행동이 분명합니다. |
| 추측 표현 '-ㄹ 수 있습니다' | ✅ 원인을 확정할 수 없으므로 맞는 표현입니다. |
| 용어 | ✅ '디스크 공간', '쓰기 권한'은 일반 사용자도 아는 말입니다. |

## 지적할 점 하나 (선택)

원인과 조치가 정확히 맞지 않습니다. 원인은 두 가지인데 조치는 '관리자에게 문의'뿐입니다. 디스크 공간 부족은 사용자가 직접 해결할 수 있는 경우가 많습니다.

고치려면 다음처럼 쓰십시오.

> 파일을 저장할 수 없습니다. 디스크 공간이 부족하거나 쓰기 권한이 없을 수 있습니다. 디스크 공간을 확보한 후 다시 시도하십시오. 문제가 계속되면 관리자에게 문의하십시오.

사용자가 디스크를 직접 관리하지 않는 환경(예: 회사 관리 PC, 서버)이라면 원문이 더 낫습니다. 이 경우에는 고치지 마십시오.

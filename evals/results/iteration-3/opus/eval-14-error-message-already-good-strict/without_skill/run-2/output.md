## 판정: 수정 필요 없음

이 메시지는 엄격 기준으로 봐도 통과합니다.

| 기준 | 결과 | 근거 |
|---|---|---|
| 문장 길이 | 통과 | 세 문장 모두 짧습니다. |
| 한 문장에 한 가지 내용 | 통과 | 순서가 **결과 → 원인 → 조치**로 나뉩니다. |
| 능동형과 명확한 주체 | 통과 | "저장할 수 없습니다"는 주어가 생략되었지만 의미가 명확합니다. |
| 용어 | 통과 | "디스크 공간", "쓰기 권한"은 표준 용어이고 한 번씩만 씁니다. |
| 불확실성 표현 | 통과 | 원인을 단정할 수 없으므로 "~일 수 있습니다"가 적절합니다. |
| 조치 지시 | 통과 | "문의하십시오"는 명령형으로 하나의 행동만 지시합니다. |
| 어조 | 통과 | 사용자를 탓하지 않고 과장된 표현도 없습니다. |

## 참고 (선택 사항)

언어 문제는 아니고 **내용 설계** 관련 사항입니다.

- 디스크 공간 부족은 사용자가 직접 해결할 수 있는 경우가 많습니다. 이 경우 조치를 두 단계로 나누는 방법이 있습니다.
  > 파일을 저장할 수 없습니다. 디스크 공간이 부족하거나 쓰기 권한이 없을 수 있습니다. 디스크 공간을 확인하십시오. 문제가 계속되면 관리자에게 문의하십시오.
- 대상 사용자가 시스템을 직접 관리하지 못하는 환경이라면 원문을 그대로 쓰는 것이 더 낫습니다.

엄격 모드라도 원문을 바꿀 언어적 이유는 없습니다.

**다듬은 문장:**

> A형은 포진성 구협염과 수족구병을, B형은 심근염과 흉막통을 일으킴. A형과 B형 모두 사람이 유일한 숙주임.

**고친 점:**

- **'~며'가 반복되던 문장을 나눔**: 원문은 '~며'로 세 마디를 이어 붙여 읽기 어려웠습니다. A형과 B형은 같은 구조라서 서술어 '일으킴'을 하나로 묶었습니다. 그래서 '일으키며/유발하며'의 반복이 사라졌습니다.
- **숙주 문장의 주어가 모호한 문제를 해결함**: 원문에서는 "사람이 유일한 숙주임"이 B형에만 해당하는지, 두 형 모두에 해당하는지 알 수 없었습니다. 콕사키바이러스는 A형과 B형 모두 사람이 유일한 자연 숙주이므로, 이를 분명하게 밝혔습니다.
- **개조식 어미 '~임'은 그대로 둠**: 원문의 문체를 따랐습니다.

앞 문맥에서 바이러스 이름이 나온다면, 둘째 문장을 "**콕사키바이러스는** 사람이 유일한 숙주임."처럼 바이러스 이름을 주어로 써도 좋습니다.

이번 PR에서는 로그인 API에 응답 캐싱을 추가했습니다. 평균 응답 시간이 약 120ms에서 40ms로 줄었습니다. 캐시 만료 시간은 5분이며, 설정 파일에서 바꿀 수 있습니다.

바꾼 점:
- 긴 문장 하나를 세 문장으로 나눴습니다.
- "추가하였으며", "감소하였습니다"를 "추가했습니다", "줄었습니다"로 바꿨습니다.
- "설정되어 있으며 … 변경이 가능합니다"를 "5분이며 … 바꿀 수 있습니다"로 줄였습니다.
- 수치(120ms, 40ms, 5분)는 그대로 두었습니다.

"80% 모드"는 원문 의미를 유지하면서 분량과 표현을 덜어내는 정도로 해석했습니다. 다르게 정의된 모드라면 기준을 알려주세요.

`~/.config/app/settings.json` 파일에서 `retry_count`를 3 이상으로 설정하면 `--force` 옵션 없이도 재시도할 수 있습니다.

**바꾼 점**
- `설정 시` → `설정하면`: 명사형 대신 조건을 나타내는 연결 어미를 써서 자연스럽게 읽힙니다.
- `옵션 사용 없이도` → `옵션 없이도`: "사용"을 빼도 뜻이 같습니다.
- `재시도 수행이 가능합니다` → `재시도할 수 있습니다`: 명사를 이어 붙인 표현 대신 동사를 썼습니다.
- `retry_count 값을` → `retry_count를`: 설정 대상이 값이라는 점은 문맥에서 드러납니다. 값을 강조하려면 `retry_count 값을`을 그대로 써도 됩니다.

코드, 경로, 옵션 이름은 바꾸지 않았습니다.

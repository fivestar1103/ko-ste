`~/.config/app/settings.json`에서 `retry_count`를 3 이상으로 설정하면 `--force` 옵션 없이도 재시도할 수 있습니다.

**바꾼 부분**
- **설정 시 → 설정하면**: 명사형 대신 연결 어미를 써서 조건이 잘 드러나게 했습니다.
- **재시도 수행이 가능합니다 → 재시도할 수 있습니다**: '수행', '가능' 같은 한자어 명사 대신 동사로 바로 표현했습니다.
- **옵션 사용 없이도 → 옵션 없이도**: '사용'은 빼도 뜻이 같습니다.
- **파일의 ~ 값을 → ~에서 ~를**: 경로와 키 이름만으로 파일과 값이라는 뜻이 전달되므로 줄였습니다.

경로, 키 이름, 옵션은 원문 그대로 두었습니다.

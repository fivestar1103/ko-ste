업로드 파일은 최대 20MB까지 허용되며 단, 관리자 계정의 경우 100MB까지 허용되나 동영상 파일(mp4, mov)은 계정 종류와 관계없이 50MB를 초과할 수 없고, 초과 시 업로드가 자동으로 취소되며 이미 업로드된 일부 데이터는 24시간 이내에 삭제됩니다.

그대로 둠: 문장을 나누거나 제한을 목록으로 풀지 않았습니다. 그렇게 하면 아래 '초과 시'가 걸리는 범위를 하나로 정하게 됩니다.

확인 필요: '초과 시'가 무엇을 초과한 경우인지 원문만으로는 정할 수 없습니다. 동영상 50MB를 초과한 경우만 가리킬 수도 있고, 20MB·100MB 제한을 포함한 모든 용량 제한을 초과한 경우일 수도 있습니다. 어느 쪽인지 정해 주시면 제한별 목록과 초과 시 처리를 나눠서 다시 쓰겠습니다.

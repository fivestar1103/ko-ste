**배치 서버만 재시작하는 경우**
> API 서버는 요청을 검증합니다. 배치 서버는 로그를 압축하며, 매일 03:00에 재시작됩니다.

**두 서버 모두 재시작하는 경우**
> API 서버는 요청을 검증하고, 배치 서버는 로그를 압축합니다. 두 서버는 모두 매일 03:00에 재시작됩니다.

**수정한 부분**
- "~하며, ~하며"로 이어지던 연결을 끊어 서버마다 역할을 따로 적었습니다.
- 재시작 대상을 문장 안에서 명시했습니다.
- "새벽 3시"를 "03:00"으로 바꿨습니다. 운영 문서라면 시간대(예: KST)도 함께 적는 것을 권합니다.

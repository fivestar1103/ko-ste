업로드 파일은 최대 20MB까지 가능합니다. 단, 관리자 계정은 100MB까지 허용됩니다. 동영상 파일(mp4, mov)은 계정 종류와 관계없이 50MB를 초과할 수 없습니다. 초과하면 업로드가 자동으로 취소되고, 이미 업로드된 일부 데이터는 24시간 이내에 삭제됩니다.

그대로 둠: '초과하면 … 취소되고, … 삭제됩니다'는 한 문장으로 두었습니다. 둘로 나누면 데이터 삭제가 한도를 초과하지 않은 경우에도 일어나는 일로 읽힐 수 있습니다.
확인 필요: '초과하면'이 무엇을 초과한 경우인지 원문만으로는 정할 수 없습니다. 동영상의 50MB 한도만 가리킬 수도 있고, 20MB·100MB 한도를 초과한 경우까지 포함할 수도 있습니다.

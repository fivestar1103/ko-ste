**다듬은 문장 (엄격 모드)**

> 인증 토큰이 만료되면 서버는 요청을 거부합니다. 토큰 만료로 요청이 거부되면, 클라이언트는 새 토큰을 받기 전에 같은 요청을 다시 보내지 않아야 합니다.

**바꾼 점**

1. **한 문장에 하나의 내용**: 원문은 서버의 동작(거부)과 클라이언트의 의무(재전송 금지)를 한 문장에 담았습니다. 두 문장으로 나눴습니다.
2. **조건을 두 번째 문장에도 적음**: 문장을 나누면 "토큰이 만료되면"이라는 조건이 둘째 문장에서 빠집니다. 그러면 클라이언트 의무가 모든 거부 응답에 적용되는 것처럼 읽힐 수 있습니다. 그래서 "토큰 만료로 요청이 거부되면"을 다시 적어 적용 범위를 고정했습니다.
3. **행위자를 명시**: "요청이 거부되며"는 피동형이라 누가 거부하는지 드러나지 않습니다. "서버는 요청을 거부합니다"로 주체를 밝혔습니다.
4. **"전까지" → "전에"**: 금지 조건의 시점을 더 단순한 표현으로 바꿨습니다. 뜻은 같습니다.

**확인할 점**: 거부 주체를 "서버"로 가정했습니다. 문서에서 다른 용어를 쓰면(예: "API 게이트웨이", "인증 서버") 그 용어로 바꾸세요.

**다듬은 문장**

> 로그인 API는 응답을 캐시합니다. 캐시를 사용하면 평균 응답 시간이 약 120ms에서 약 40ms로 줄어듭니다. 캐시 만료 시간의 기본값은 5분입니다. 설정 파일에서 만료 시간을 바꿀 수 있습니다.

**바꾼 점**

- **"이번 PR에서는 … 추가하였으며"를 삭제했습니다.** 사용자용 설정 안내문이므로 변경 이력 대신 현재 동작을 설명합니다.
- **긴 문장을 나누었습니다.** 두 문장에 정보가 네 개 있었습니다. 이를 한 문장에 정보 하나씩, 네 문장으로 나누었습니다.
- **"감소하였습니다"를 "줄어듭니다"로 바꾸었습니다.** 한자어 대신 쉬운 우리말을 쓰고, 현재 시제로 맞추었습니다.
- **"설정되어 있으며"를 "기본값은 5분입니다"로 바꾸었습니다.** 사용자가 바꿀 수 있는 값이므로 "기본값"으로 명시했습니다.
- **"변경이 가능합니다"를 "바꿀 수 있습니다"로 바꾸었습니다.** 명사형 표현을 동사형으로 바꾸었습니다.
- **"40ms" 앞에도 "약"을 붙였습니다.** 두 값 모두 평균 측정값이므로 표기를 맞추었습니다.

**확인이 필요한 점**

마지막 문장은 아직 모호합니다. 사용자가 실제로 값을 바꾸려면 파일 이름, 키 이름, 단위가 필요합니다. 이 정보를 알려 주시면 다음과 같이 고치겠습니다.

> `config.yaml`의 `login_cache_ttl` 값(초 단위)을 바꾸면 만료 시간을 변경할 수 있습니다.

(위 파일 이름과 키 이름은 예시입니다.)

**다듬은 문장 (엄격 모드)**

> 로그인 API는 응답을 캐시합니다.
> 이 캐시로 평균 응답 시간이 약 120ms에서 약 40ms로 줄었습니다.
> 캐시 만료 시간의 기본값은 5분입니다.
> 설정 파일에서 캐시 만료 시간을 바꿀 수 있습니다.

**바꾼 점**

- **한 문장에 한 내용만 담았습니다.** "~하였으며", "~되어 있으며"로 이어진 긴 문장을 네 문장으로 나눴습니다.
- **"이번 PR에서는"을 뺐습니다.** 사용자용 설정 안내문에서는 PR이 무엇인지 알 필요가 없습니다. 기능이 지금 어떻게 동작하는지만 쓰면 됩니다.
- **딱딱한 표현을 쉬운 말로 바꿨습니다.** "추가하였으며"는 "캐시합니다"로, "감소하였습니다"는 "줄었습니다"로, "변경이 가능합니다"는 "바꿀 수 있습니다"로 고쳤습니다.
- **"~를 통해"를 줄였습니다.** "이를 통해"는 "이 캐시로"로, "설정 파일을 통해"는 "설정 파일에서"로 바꿨습니다.
- **"약"이 두 숫자 모두에 걸리게 했습니다.** 원문에서는 "약"이 120ms에만 붙는 것처럼 읽힐 수 있습니다.
- **"설정되어 있으며"를 "기본값은"으로 바꿨습니다.** 사용자가 바꿀 수 있는 값이므로 기본값이라고 써야 정확합니다.

**더 고치면 좋은 점**

설정 파일의 이름과 키 이름을 쓰면 사용자가 바로 따라 할 수 있습니다. 예를 들면 다음과 같습니다.

> `config.yaml` 파일의 `cache.ttl` 값으로 캐시 만료 시간을 바꿀 수 있습니다.

실제 파일 이름과 키 이름을 알려주시면 문장에 넣어 드리겠습니다.

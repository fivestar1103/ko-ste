원문은 "매일 새벽 3시에 재시작됨"이 배치 서버에만 해당하는지 두 서버 모두에 해당하는지 불분명합니다. 의도에 맞는 쪽을 고르세요.

**두 서버 모두 재시작되는 경우**
> API 서버는 요청을 검증하고, 배치 서버는 로그를 압축한다. 두 서버는 매일 새벽 3시에 재시작된다.

**배치 서버만 재시작되는 경우**
> API 서버는 요청을 검증한다. 배치 서버는 로그를 압축하며, 매일 새벽 3시에 재시작된다.

수정한 부분은 다음과 같습니다.
- "~하며"가 두 번 반복되어 첫 번째는 "~하고"로 바꾸거나 문장을 나눴습니다.
- 재시작의 대상을 명시했습니다.
- 문서의 다른 부분이 개조식(`-함`, `-됨`)이라면 `…압축함. 두 서버는 매일 새벽 3시에 재시작됨.`처럼 어미만 맞추면 됩니다.

시간대(예: KST)가 중요하다면 "새벽 3시(KST)"처럼 덧붙이는 것도 좋습니다.

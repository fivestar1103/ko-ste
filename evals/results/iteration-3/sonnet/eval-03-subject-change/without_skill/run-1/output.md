**추천안**
> 비밀번호 재설정을 요청하면 링크가 이메일로 발송됩니다. 링크는 30분 후 만료되며, 만료된 경우 다시 요청해야 합니다.

**바꾼 점**
- 한 문장에 주어가 섞여 있었습니다(사용자가 요청, 링크가 발송·만료, 사용자가 재요청). 두 문장으로 나누고 "링크는"을 명시했습니다.
- "요청하면 … 발송되며 … 만료되고 … 요청해야"처럼 연결어미가 길게 이어지던 것을 끊었습니다.
- "30분이 지나면 만료되고 다시 요청해야 합니다"는 조건과 결과가 뒤엉켜 있어서 "30분 후 만료되며, 만료된 경우 다시 요청"으로 정리했습니다.

**한 문장으로 쓰고 싶다면**
> 비밀번호 재설정 링크는 요청 시 이메일로 발송되며, 30분 후 만료되므로 이후에는 다시 요청해야 합니다.

UI 문구처럼 짧아야 한다면 이렇게도 쓸 수 있습니다.
> 재설정 링크는 이메일로 발송되며 30분 후 만료됩니다. 만료되면 다시 요청해 주세요.

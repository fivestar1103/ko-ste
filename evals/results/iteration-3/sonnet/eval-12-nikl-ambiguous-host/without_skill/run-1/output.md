**다듬은 문장**

> A형은 포진성 구협염과 수족구병을, B형은 심근염과 흉막통을 일으키며, 두 유형 모두 사람이 유일한 숙주이다.

**바꾼 점**
- "일으키며 / 유발하며"가 반복되고 어휘도 섞여 있어, 서술어를 하나로 묶고 B형 앞의 반복을 줄였습니다.
- 마지막 절의 주어가 모호해서 "두 유형 모두"를 넣어 A형과 B형 모두에 해당함을 분명히 했습니다.
- 문장 끝은 "임" 대신 "이다"로 바꿨습니다.

**개조식(보고서, 요약표)에 쓰신다면**

> A형은 포진성 구협염·수족구병, B형은 심근염·흉막통을 유발하며, 두 유형 모두 사람이 유일한 숙주임.

원문이 특정 바이러스(예: 콕사키바이러스)에 대한 설명이라면 첫머리에 바이러스 이름을 넣는 편이 더 명확합니다.

# 배포 구조 변경 후 동작 점검

국립국어원 인용문을 실행 스킬에서 분리한 뒤, 독립 Codex 에이전트가 새 입력 6개를 처리했다. 판정자는 스킬 규칙을 읽지 않고 입력·출력만 읽었다. 정확한 모델 식별자는 노출되지 않아 추정하지 않았다. 이 결과는 개발 점검이며 일반적인 성능이나 독자의 이해도 향상을 증명하지 않는다.

- `inputs.json`: 요청 원문
- `outputs.json`: 한 번 생성한 원출력. 판정 후 고치지 않았다.
- `execution-record.md`: 실제로 읽은 자원·해시·검사 결과
- `read-snapshot/`: 읽은 지침·규칙·원자료 목록의 정확한 사본
- `reviews.json`, `audit-record.md`: 별도 평가자의 판정과 읽은 파일 해시

초기 6개에서는 본문 사실·조건·의무·수치·코드·로그의 명확한 변경이 지적되지 않았다. 다만 4번은 수정 이유를 요청했는데 규칙 코드만 제시했다. 2번의 가능성·허용 확인 메모는 불필요할 수 있다고 판정됐다. 평가자의 결과가 사람의 정답과 대조된 것은 아니다.

4번의 실패를 반영해 이유를 요청할 때 짧은 설명을 쓰도록 지침과 표를 수정했다. `followup-output.md`와 `followup-record.md`는 npm의 `skills` CLI로 설치한 수정본의 별도 요청 결과다. 기존 6개 집계에 합치지 않는다.

처음 6개를 실행할 때는 복사된 스킬 폴더를 사용했다. 이후 배포 경로를 GitHub 직접 설치와 marketplace로 바꾸었다. `read-snapshot/04-native-pairs.md`를 읽은 뒤 제외 쌍의 해설도 보완했다. 원출력은 그 변경 이전 지침의 결과다. 실행 기록의 개인 절대 경로는 자리표시로 바꾸고 원본은 Git에서 제외된 로컬 보관 위치에 보존했다.

실제 배포 설치 경로는 README의 `npx skills add`와 Claude Code marketplace다. 앞선 설치 형식은 연구 기록으로만 보존한다.
